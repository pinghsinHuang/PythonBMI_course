# BMI 橫向指針設計

- **目的：** 計算 BMI 後，在既有結果卡中用橫向分段刻度及指針呈現數值相對於臺灣成人體位區間的位置。
- **範圍：** 保留現有數值、分類、建議和門檻（18.5、24、27）；新增可隨 BMI 定位的視覺刻度，並提供文字標籤以維持易讀與無障礙。
- **不包含：** 不變更 BMI 計算或分類，不新增前端套件，也不調整未計算前的插圖。
- **方案比較：** 半圓弧儀表最具傳統儀表感；圓形刻度較緊湊但分類對照較不直覺；橫向區間指針較易閱讀且省空間，使用者選擇此方案。
- **實作決策：** 沿用 Flask/Jinja 與現有 CSS；以伺服器計算出的 BMI 和既有區間決定指針位置，窄螢幕亦須可讀，不依賴 JavaScript。
